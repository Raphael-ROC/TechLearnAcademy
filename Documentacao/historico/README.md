# Documentação de etapas anteriores

Os textos desta pasta foram preservados para consulta acadêmica e registram decisões e verificações de versões anteriores. Podem mencionar pastas de outro computador, quantidades antigas, arquivos de evidência que não são públicos e funcionalidades que evoluíram.

Não use esses textos como instrução de implantação atual. Os guias atuais estão no [README principal](../../README.md), em [arquitetura](../arquitetura.md), [execução](../executar-localmente.md), [publicação](../publicacao.md) e [verificação](../verificacao.md).

Os arquivos de banco, backups, PDFs de materiais e imagens com dados de contas não acompanham este histórico. As menções a testes anteriores não são resultados reexecutados durante a organização deste repositório.
