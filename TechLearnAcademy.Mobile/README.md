# Protótipo .NET MAUI

Esta pasta preserva o protótipo anterior de aplicativo mobile em C#/.NET MAUI.

O aplicativo Android oferecido na página pública foi desenvolvido em Java e está em `../TechLearnAcademy.Android`. O protótipo MAUI não faz parte da solução principal nem do fluxo de publicação atual.

Para estudar este protótipo, abra seu `.csproj` em um ambiente com as cargas de trabalho MAUI apropriadas. A presença dos fontes não indica que esta versão tenha sido instalada ou validada em celular.
